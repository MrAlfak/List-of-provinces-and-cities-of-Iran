# Support

Thanks for using the Iran Provinces & Cities Dataset.

## Data correction

Open a **Data correction** issue when you find:

- a missing or unexpected city;
- a province/county/district hierarchy issue;
- a newer administrative change after the current 1402 snapshot;
- an incorrect coordinate;
- a weak or incorrect English name.

For membership/hierarchy changes, include an official or clearly traceable source and the effective date/snapshot whenever possible.

## Bug report

Open a **Bug report** issue for problems with:

- the REST API;
- Docker;
- generators;
- validation/audit scripts;
- SQL exports;
- CSV/GeoJSON generation;
- documentation examples.

## Feature request

Open a **Feature request** issue for integrations, formats, tooling or developer-experience improvements that can benefit multiple users.

## Before opening an issue

Please check existing issues and include a minimal reproducible example when the problem is code-related.

## Help the project

If the project is useful to you, the most helpful actions are:

- ⭐ Star the repository.
- 🔗 Link to it from projects that use the dataset.
- 🐛 Report sourced data issues.
- 🤝 Submit focused pull requests.
- 📣 Share it with developers building Iranian address, ecommerce, logistics, GIS or data applications.
