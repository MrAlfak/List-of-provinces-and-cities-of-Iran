# لیست استان‌ها و شهرهای ایران (Iran Provinces and Cities)

این مخزن شامل لیست جامع و به‌روز استان‌ها و شهرهای ایران در قالب فرمت‌های استاندارد است.

## ویژگی‌ها (Features)
- 📊 **داشبورد وب**: رابط کاربری مدرن برای مشاهده و جستجوی بصری.
- ✅ **لیست کامل**: شامل ۳۱ استان و تمامی شهرهای مهم.
- 🌍 **دو زبانه**: نام انگلیسی هر استان برای استفاده در Slug و API.
- ☎️ **اطلاعات مخابراتی**: پیش‌شماره تلفن هر استان.
- 📂 **فرمت‌های متنوع**: خروجی JSON و CSV برای استفاده در انواع پروژه‌ها.

## محتویات (Contents)
- **iran_cities.json**: منبع اصلی داده‌ها.
- **iran_cities.csv**: نسخه CSV داده‌ها برای دیتابیس و اکسل.
- **index.html**: داشبورد وب (رابط کاربری).
- **search.py**: اسکریپت جستجوی ترمینال.
- **export_csv.py**: اسکریپت تبدیل داده‌ها.

## نحوه استفاده (Usage)

### مشاهده داشبورد وب:
کافیست فایل `index.html` را در مرورگر خود باز کنید.

### جستجو در ترمینال:
```bash
python search.py اصفهان
```

### تبدیل به CSV:
```bash
python export_csv.py
```

## ساختار داده JSON
```json
{
  "province": "نام استان",
  "english_name": "Province Name",
  "phone_code": "0XX",
  "cities": ["شهر ۱", "شهر ۲"]
}
```
