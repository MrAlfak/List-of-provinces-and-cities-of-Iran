# Security Policy | خط‌مشی امنیتی

## Supported Versions | نسخه‌های پشتیبانی شده

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability | گزارش آسیب‌پذیری

### فارسی

اگر آسیب‌پذیری امنیتی در این پروژه پیدا کردید:

1. **لطفاً به صورت عمومی Issue باز نکنید**
2. به آدرس ایمیل نگهدارنده پروژه ایمیل بزنید
3. شرح کامل مشکل را ارائه دهید
4. در صورت امکان، راه‌حل پیشنهادی ارائه دهید

ما در اسرع وقت به گزارش شما رسیدگی خواهیم کرد.

### English

If you discover a security vulnerability in this project:

1. **Please do NOT open a public issue**
2. Email the project maintainer directly
3. Provide a detailed description of the issue
4. If possible, suggest a solution

We will address your report as soon as possible.

## Security Best Practices | بهترین شیوه‌های امنیتی

### For API Users

- Always validate and sanitize user input
- Use HTTPS in production
- Implement rate limiting
- Add authentication for sensitive endpoints
- Keep dependencies up to date

### For Contributors

- Never commit sensitive data (API keys, passwords, etc.)
- Use environment variables for configuration
- Follow secure coding practices
- Run security tests before submitting PRs

## Known Issues | مشکلات شناخته شده

Currently, there are no known security issues.

## Updates | بروزرسانی‌ها

Security updates will be released as patch versions (e.g., 2.0.1, 2.0.2).
